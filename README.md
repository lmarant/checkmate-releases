# CheckMate — εκδόσεις

Τελευταία έκδοση: **2.17.0** (13/11/2026)

Η υποστήριξη μπορεί πλέον να κάνει ρυθμίσεις και διορθώσεις απομακρυσμένα, χωρίς AnyDesk· κάθε ενέργεια καταγράφεται στο Ημερολόγιο ενεργειών. Νέο: πρόσθετα ειδικά για την επιχείρησή σας (IT → Πρόσθετα & απομακρυσμένα).

Όσοι έχουν ήδη CheckMate ενημερώνονται από το πρόγραμμα (Ρυθμίσεις → Ενημερώσεις).
Κάθε ενημέρωση είναι ψηφιακά υπογεγραμμένη· το CheckMate απορρίπτει οτιδήποτε δεν έχει τη σωστή υπογραφή.
