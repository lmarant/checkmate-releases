# CheckMate — εκδόσεις

Τελευταία έκδοση: **2.10.8** (22/10/2026)

Δεν γίνεται πλέον «πίσω» με σάρωση στο touchpad. Αν υπάρχουν ανοιχτές οθόνες, το CheckMate ρωτά πριν κλείσει. Οι ανοιχτές οθόνες κρατιούνται.

Όσοι έχουν ήδη CheckMate ενημερώνονται από το πρόγραμμα (Ρυθμίσεις → Ενημερώσεις).
Κάθε ενημέρωση είναι ψηφιακά υπογεγραμμένη· το CheckMate απορρίπτει οτιδήποτε δεν έχει τη σωστή υπογραφή.
