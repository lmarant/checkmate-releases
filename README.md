# CheckMate — εκδόσεις

Τελευταία έκδοση: **2.16.0** (03/11/2026)

Αξιόγραφα (επιταγές και συναλλαγματικές με χαρτοφυλάκιο, λήξεις, κατάθεση, μεταβίβαση, σφράγιση), συμψηφισμοί πελάτη–προμηθευτή, μεταφορά πελατών/προμηθευτών με υπόλοιπα από άλλο πρόγραμμα, αρχείο Excel για τον λογιστή.

Όσοι έχουν ήδη CheckMate ενημερώνονται από το πρόγραμμα (Ρυθμίσεις → Ενημερώσεις).
Κάθε ενημέρωση είναι ψηφιακά υπογεγραμμένη· το CheckMate απορρίπτει οτιδήποτε δεν έχει τη σωστή υπογραφή.
