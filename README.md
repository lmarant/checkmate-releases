# CheckMate — εκδόσεις

Τελευταία έκδοση: **2.10.9** (22/10/2026)

Το CheckMate ζητά πλέον ενεργοποίηση: κωδικό σύνδεσης της συνδρομής CheckMate Cloud ή κλειδί άδειας. Σαφή μηνύματα όταν ένας κωδικός είναι λάθος.
